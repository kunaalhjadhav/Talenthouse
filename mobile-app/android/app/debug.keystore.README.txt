A debug.keystore is a binary Java keystore file, not something that can be safely
authored as text. Generate one locally with:

  keytool -genkeypair -v -storetype PKCS12 -keystore debug.keystore \
    -alias androiddebugkey -keyalg RSA -keysize 2048 -validity 10000 \
    -storepass android -keypass android \
    -dname "CN=Android Debug,O=Android,C=US"

Place the resulting debug.keystore file in this app/ folder. For release signing,
generate a SEPARATE keystore (see DEPLOYMENT.md §11) — never ship the debug key.
