Add this to mobile-app/package.json under "dependencies":

  "react-native-razorpay": "^2.3.0"

Then:
  cd TalentApp
  npm install react-native-razorpay@^2.3.0

ANDROID LINKING (react-native-razorpay needs this — not automatic):
1. In android/app/build.gradle, add inside dependencies {}:
     implementation project(':react-native-razorpay')
2. In android/settings.gradle, add:
     include ':react-native-razorpay'
     project(':react-native-razorpay').projectDir = new File(rootProject.projectDir, '../node_modules/react-native-razorpay/android')
3. In android/app/src/main/java/.../MainApplication.java (or .kt), add to the
   getPackages() list:
     new RazorpayPackage()
   and import it:
     import com.razorpay.rn.RazorpayPackage;

Full official instructions (in case the library version changes these steps):
https://github.com/razorpay/react-native-razorpay#readme

Then rebuild:
  cd android && .\gradlew clean
  cd ..
  npx react-native run-android
